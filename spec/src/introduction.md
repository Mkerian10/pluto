# Introduction

This is the formal specification of the Pluto programming language.

Pluto is a domain-specific programming language for distributed backend systems with geographic awareness. It compiles to native code and treats distribution, inter-service communication, and dependency management as first-class language concerns.

This specification defines the syntax, type system, and semantics of the language. It serves as the authoritative reference for the language's behavior — if the compiler disagrees with this document, the compiler has a bug.
